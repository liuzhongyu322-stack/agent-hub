# yunnan-trip · 项目记忆

## 关键决策

- 主线锁定「滇西北进川西」阶梯海拔（昆明 1890 → 大理 2000 → 丽江 2400 → 香格里拉 3280 → 亚丁 4600），高反适应最优。
- 玉龙雪山砍掉（11 月云多看到真容是抽卡，门票+索道人均 500 不划算）。
- 南极洛：正规景区（有票有观光车），替掉禁入名单上的阿布吉措。
- 雨崩优于稻城：零折返、11 月窗口最佳；稻城要折返 + 长途山路。
- 虎跳峡走中虎跳精华段（下江看虎跳石），不走高路（高路在禁入通告名单上）。

## 用户偏好

- 交通省钱为主、方便为辅，首选官方渠道（12306 / 彩云通 / 官方小程序），拼车只作兜底且走客栈渠道。
- 票务分「先锁死」与「到了再买」两档，不默认全提前抢（淡季）。
- 行程要 A/B 方案留活口，不非 A 即 B；用户会按实际情况灵活调整。
- 行李全程安排寄存点（虎跳峡 Tina's 行李房、巴迪客栈、飞来寺客栈）。
- 交付要「保姆级、手机可开、可分享」，一个文件带齐。

## 事实核验（易错点）

- 红嘴鸥 10/31 只在滇池海埂大坝（先头部队几千只），翠湖要 11 月中下旬。
- 转经筒在独克宗龟山公园，免费；「大经幡」在纳帕海环湖路边，顺路。
- 巴迪→德钦无班车可指望（巴迪是途经站），拼车 60/人。
- 香格里拉→稻城每天仅 07:30 一班。
