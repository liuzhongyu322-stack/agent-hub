# fitcheck · 个人合身判定系统

买衣服前，用你的净体数据和成衣尺码表，算出这件衣服在你身上是紧是松、下摆落到哪、袖长到哪。**纯算术 + 规则引擎，零依赖、零模型调用，每个结论都能复核到厘米。**

## 为什么不用 AI 试穿

现有换装模型有 well-fitted bias（训练数据里没有"穿小两码"的样本，模型会自动把衣服改合身）。所以准确性不能交给生成模型，只能靠算术；生成图只适合最后当展示。

## 使用方式

### 方式一：对话（推荐）
把商品尺码表截图发给你的 AI 助手，说一句"跑判定"即可。助手负责建衣服记录、跑引擎、出判定卡。

### 方式二：命令行
```bash
# 录入：复制 data/garments/ 下任一 json 改参数
python3 run.py                     # 跑全部衣服
python3 run.py 关键字              # 只跑一件
python3 run.py --calibrate         # 查看个人松量标定进度
```

判定卡输出在 `out/`，单页 HTML，A4 可打印。

## 录入一件衣服需要什么

尺码表里常见参数的口径（全部 cm，围度一律整圈，平铺半围要 ×2）：

| 字段 | 口径 |
|---|---|
| shoulder 肩宽 | 两肩缝直线距离 |
| bust 胸围 | 袖窿下 2cm 整圈 |
| length 衣长 | 后中领口 → 下摆 |
| sleeve_length 袖长 | 肩缝 → 袖口 |
| waist / hip / inseam（下装） | 腰口整圈 / 臀最丰满整圈 / 裆缝→裤口 |

衣服记录可附加字段：
- `thickness` 厚度：thin / mid / thick / wool / padded
- `stretch` 弹性：none / slight / medium / high
- `drape` 垂坠度：structured（挺括）/ regular（常规）/ fluid（垂坠）——决定必需松量底线
- `fit_goal` 目标效果：tight / fitted / relaxed / oversize + `vibe` 一句话描述想要的感觉
- `feedback` 实穿反馈：`{"bust": "ok"}` 等，攒 5 条自动启用个人松量标定

## 净体档案

`data/body.json`。关键口径：肩宽必须是**肩峰骨点**直线距离（不是三角肌最鼓处，健身体型最易错，差 3-5cm）。量法详见 `01-量法规范.html`。

个人偏好写在 `fit_preference` 字段（如 shoulder=muscle_fit：肩部微紧判"显肩线"而非顶死）。

## 判定逻辑（四笔账）

```
有效松量 = 成衣围度 − 净体围度 − 面料厚度惩罚(4×mm) − 内衣占量 − 内搭占量
可穿余量 = 有效松量 + 弹性可借量（弹力帮你穿进去，但改变不了镜子里的样子）
```

- 每个部位独立判底线（肩宽骨性不可压、腰围可压 4-6cm），总体结论取最短板
- 垂坠度、个人偏好、目标效果只改门槛和注解，不改数字
- 参数缺失一律如实降级为"数据不足"，不编造落点
- 25 条验收断言：`python3 tests/test_assertions.py`
